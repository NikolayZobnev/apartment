# Технический дизайн квартиры в ЖК «Гарантия»

Рабочие требования семьи к перепланировке и техническому дизайну квартиры. Текущая версия собрана 10 октября 2026 года по ответам владельца и списку пожеланий его жены.

- [Актуальные требования и открытые вопросы](docs/requirements.md).
- [Обмерный план](artifacts/ЖК%20ГАРАНТИЯ%20—%20обмерный%20план.pdf).

Общая площадь по плану — 95,78 м², высота потолков — 2760 мм. Размеры требуют проверки на месте.

Документ требований предназначен для разработки планировочных вариантов и технических решений. Открытые вопросы и задачи проверки указаны отдельно; документ не является готовым строительным проектом. Бюджет и декоративная отделка стен на текущем этапе не рассматриваются.
